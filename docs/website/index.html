PlainScript vs JavaScript

PlainScript

server.ps 
use express

remember app as express()

route "/" get:
  reply "Hello, World!"

listen 3000

JavaScript

server.js 
const express = require('express');

const app = express();

app.get('/', (req, res) => {
  res.send('Hello, World!');
});

app.listen(3000);

PlainScript

db.ps 
use sqlite

database "mydb.sqlite"

query "SELECT * FROM users" as results
show results

JavaScript

db.js 
const Database = require('better-sqlite3');

const db = new Database('mydb.sqlite');

const results = db.prepare(
  'SELECT * FROM users'
).all();

console.log(results);

FAQ

Frequently Asked Questions

What is PlainScript?

PlainScript is an Intent-Oriented Programming Language that compiles to JavaScript. You write in English-like syntax and the compiler generates production-ready JS.

How is it different from JavaScript?

PlainScript lets you express intent directly. Instead of memorizing APIs, you describe what you want done. The compiler handles the implementation.

Can I use npm packages?

Yes! PlainScript supports the full npm ecosystem. Use use express, use sqlite, or any other package.

Is PlainScript production ready?

PlainScript compiles to JavaScript, so you get all the production benefits of the JS ecosystem. The compiler is actively developed and tested.

What Node.js version do I need?

Node.js 18 or later is recommended.

Where can I report bugs?

Open an issue on GitHub at github.com/ayoistooslick/plain-code/issues
