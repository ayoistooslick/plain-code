FAQ

Frequently asked questions

What is PlainScript?

PlainScript is an Intent-Oriented Programming Language that compiles to JavaScript. It lets you write code using plain English-like syntax, while the compiler handles the underlying implementation details.

How is PlainScript different from JavaScript?

PlainScript focuses on intent rather than implementation. Instead of writing low-level JavaScript, you describe what you want to accomplish. The compiler translates your intent into optimized JavaScript code.

Can I use npm packages with PlainScript?

Yes. Use the use keyword to import any npm package. Since PlainScript compiles to JavaScript, the entire npm ecosystem is fully compatible with your PlainScript projects.

Does PlainScript have built-in database support?

Yes. PlainScript includes first-class SQLite support with the database, query, and insert keywords. It works with both native SQLite and WebAssembly builds.

Can I mix PlainScript and JavaScript?

Absolutely. Use the javascript keyword to embed raw JavaScript directly in your PlainScript files. This gives you full access to JavaScript when you need low-level control.

Is PlainScript production-ready?

PlainScript is currently in active development and is not yet at a stable production release. We recommend trying it out for personal projects and prototypes. Check the GitHub repository for the latest status and roadmap.
