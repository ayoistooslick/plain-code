PlainScript vs JavaScript

Web Server

PlainScript 
use express

remember app as express

when someone goes to "/"
  send "Hello, World!"

listen 3000
JavaScript (Express) 
const express = require("express");
const app = express();

app.get("/", (req, res) => {
  res.send("Hello, World!");
});

app.listen(3000);

Database

PlainScript 
database users

insert into users remember
  name as "Alice"
  age as 30

remember result as query "SELECT * FROM users"
show result
JavaScript (better-sqlite3) 
const Database = require("better-sqlite3");
const db = new Database("users.db");

db.prepare(
  "INSERT INTO users (name, age) VALUES (?, ?)"
).run("Alice", 30);

const result = db.prepare(
  "SELECT * FROM users"
).all();
console.log(result);

FAQ

Frequently asked questions

What is PlainScript?

PlainScript is an Intent-Oriented Programming Language (IOPL). Instead of writing imperative step-by-step instructions, you describe what you want to achieve and the compiler generates the equivalent JavaScript for you.

How is PlainScript different from JavaScript?

PlainScript uses human-readable keywords like remember, when, show, and plus instead of traditional syntax. The compiler translates your intent-based code into standard JavaScript, so it runs anywhere JavaScript runs.

Can I use npm packages with PlainScript?

Yes! Use the use keyword to import any npm package. PlainScript compiles to Node.js-compatible JavaScript, so the entire npm ecosystem is available.

Does PlainScript have built-in database support?

Yes. PlainScript includes first-class SQLite support with keywords like database, query, and insert. It can use native SQLite or compile to WebAssembly for browser environments.

Can I mix PlainScript and JavaScript?

Absolutely. Use the javascript keyword to embed raw JavaScript code directly within your PlainScript files when you need low-level control or want to use a specific JS API.

Is PlainScript production-ready?

PlainScript is currently in active development (v0.1.7). While it is stable enough for prototyping and small-to-medium projects, we recommend evaluating it carefully before using it in critical production systems.
