# PLINJS Language Extension — Changelog

## [0.1.7]

- Initial release of the PLINJS language extension
- Syntax highlighting for all PLINJS keywords via the bundled TextMate grammar (`source.plinjs`)
- Snippets for common PLINJS patterns
- Language configuration: auto-closing pairs, comment toggling, bracket matching, code folding
- File icon for `.pln` files
- Language registration for `.pln` as PLINJS source
